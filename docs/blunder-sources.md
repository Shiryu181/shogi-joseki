# 級位者の悪手の出どころ(調査)

調査日: 2026-11-08。調べただけで、アプリとデータは変えていない。
確かめられなかったことは「未確認」と書く。法的な判断は私にはできないので、規約の文言を引くだけにした。

## 結論

- **大量の棋譜を、規約の面で安心して使える入口は見つからなかった。**
  - 将棋ウォーズ: 規約が棋譜の複製・配布・営業使用を禁じ、私的使用以外の利用も許可制。アプリでの集計・公開は **使えない可能性が高い(HEROZに許可を取れば別)**。
  - 将棋倶楽部24: **2025-12-31 にサービス終了**。新しい棋譜は増えない。規約は確認できず(未確認)。
  - 81Dojo: 規約で棋譜の共有が明確に許されている(商用は事前相談)。ただし **級位者の棋譜は少なく、一括取得の窓口も未確認**。
  - lishogi: 棋譜の一括データベースの公開は **確認できず(未確認)**。
- **現実的に使えそうなのは次の2本立て。**
  1. **出典の「よくある悪手」を拾う**(書籍・講座)。今のアプリが出典+エンジン検証で作っているやり方と同じで、規約の問題がない。量は少ない。
  2. **81Dojo の公開棋譜で到達数・手の分布を数える**(規約上は可能に読めるが、窓口と量が未確認なので、先に小さく試す)。
- **将棋ウォーズの棋譜は、使うなら HEROZ に問い合わせて許可を得てから。** 許可なしで集計するのは勧めない。
- 棋譜集計がだめでも、**「級位者が指しがちな型」を出典で決め、エンジンで損を測る**ので、ユーザーの方針(損の線は下げない)は守れる。

## 1. 棋譜の入手先と、使ってよいか

### 将棋ウォーズ(HEROZ)
- 利用規約 第6条第3項: 「本サービスおよび本サービスに関連する一切の情報(棋譜を含みます)についての著作権およびその他知的財産権はすべてHEROZに帰属」(ユーザー投稿情報の著作権を除く)。「無断で複製、譲渡、貸与、翻訳、改変、転載、公衆送信…配布、出版、営業使用等をしてはならず」。
- 第7条第3号: 「個人としての私的使用以外の目的で利用…する行為(ただし、HEROZが許可したものを除く)」を禁止。
- 第7条第5号a: 「通常利用の範囲を超えてサーバーに負担をかける行為」を禁止。クローリングの明記はないが、大量取得は触れるおそれ。
- 出典: <https://shogiwars.heroz.jp/wars-terms.html>(規約の本文。ページ取得の要約をもとに引用。原文での再確認を推奨)
- 「ネットワーク対戦ゲームに係るHEROZ著作物の利用に関するガイドライン」という文書が別にある(<https://shogiwars.heroz.jp/terms> のリンク名)。**本文は取得できず、中身は未確認。**
- 公式に棋譜を一括提供する窓口は **見つからなかった**(未確認)。
- 棋譜に著作権があるかは法的に定説がない(弁護士の解説では「認められない」が通説的とするものもある)。ただし、規約の契約としての制約は別に残る。
  出典: <https://www.bengo4.com/c_23/n_11747/>(検索結果の要約のみ。本文は未読)
- 結論: **「棋譜を集めて集計し、アプリの内容に使う」は、規約上は許可がない限り避ける。** 自分の対局を自分で見返すのは私的使用。ただし、それを他人向けアプリの材料にするのは私的使用を超える可能性が高い。

### SHOGI-EXTEND(棋譜検索サービス)
- ウォーズの棋譜検索・解析ができる Web アプリ。ソースは AGPL-3.0(<https://github.com/akicho8/shogi-extend>)。
- **ウォーズ棋譜の取得元・一括提供の有無・データの権利は確認できなかった(未確認)。** ソースがAGPLでも、棋譜データの権利は別。
- 結論: 棋譜の出どころがウォーズである以上、ウォーズ規約の制約が残ると考えるのが安全。使うなら運営者に聞く。

### 81Dojo
- 規約 第5条: 「All users can freely watch any game and freely access the kifu of the game」「Anyone can share (in blog, SNS, online video, etc.) the kifu or the game」。共有してよいのは棋譜・指し手・対局者名のみ(チャットは不可)。「商用で共有するときは事前に相談を」。第5.1条: 自分の対局の棋譜に権利を主張できない(事実の記録だから)。
- 第4.1条: 他のツール・ソフトでサーバーに接続することは強く禁止(スクレイピングの明記はない)。
- 出典: <https://81dojo.com/en/terms.html>
- 棋譜は1局ずつ KIF/CSA で保存できる。大会ページには局ごとの棋譜リンクがある(例: <https://system.81dojo.com/en/tournaments/4756/games>)。**一括ダウンロードは見つからなかった。**
- 欠点: 利用者は国際的で、棋力の表示も将棋ウォーズの級とは別。**「ウォーズ10級〜1級相当」で絞る方法は未確認。** 中飛車・三間飛車の棋譜が十分あるかも未確認。
- 結論: 規約上は最も使いやすい。ただし、アプリの題材(級位者の悪手)に合う量と質があるかは、小さく試さないと分からない。

## 3. 棋譜が手に入った場合の進め方(案)

1. 対象: 中飛車・三間飛車で、10級〜1級(または相当)の対局。
2. 各棋譜を `joseki` の本線の局面にたどらせ、**本線の相手の番の局面ごとに「到達数」と「指された手の分布」**を数える。
3. 到達数が一定以上(目安: 20局以上。**根拠のない目安**)の局面で、指された手のうち、エンジンの損が230以上のものを咎めの候補にする。
4. 候補は、今の咎めと同じ条件(20手指し継いでも得が残る・盤で得が見える・自然な手)で絞る。「損230」は下げない。
5. 出す問題に「この局面でよく指される」を添えるなら、**実数は出さず**「よく指される」程度にする(規約対策)。

量の目安(推定。確認していない):
- 本線は章ごとに20〜30手ほど。局面の到達数は手数が進むほど急に減る。10手目あたりまでは数十局で足りても、20手目以降は **1局面に20局が集まるには、戦法ごとに数万局が要る** と見る。
- 一方、咎めが0本の章(9章)は、深い局面が多いと思われる。そこは棋譜を集めても数が足りない可能性が高い。
- 手間の見積もり(推定): 棋譜の取得と整形に1〜2日、集計スクリプトに1日、エンジン測定は今の `find-punishments.cjs` が使える。**ただし最初の課題は量と規約で、実装ではない。**

## 4. 棋譜が使えない場合の代わりの案

- **案A: 出典の「よくある悪手」だけを使う。** 上の書籍・講座から、悪手とされる手とその咎め方を拾い、エンジンで損を測る。出典+エンジン検証の方針と合う。欠点: 「級位者が指しがち」の根拠は、本の記述に頼る。量が少ない。
- **案B: ユーザー本人の対局を使う。** 本人のウォーズ棋譜での「相手の悪手」は、私的な見返りの範囲。アプリに載せるのは「自分の経験で見つけた型」にとどめ、他人の棋譜や名前は出さない。量は少ない。規約上の扱いは、使い方次第で私的使用を超えるので、HEROZに確認するのが安全(未確認)。
- **案C: エンジンの候補の順位で「人間らしい手」を探す。** MultiPV の上位が良手で、10位以下に見た目が自然な悪手があれば、それを候補にする。級位者がその手を指す根拠はないので、「よく指される」とは書けない。今の方式の延長にすぎない。
- **案D: HEROZに許可を得る。** 許可が出れば棋譜集計が使える。許可の見込みは未確認。時間はかかる。
- **案E: 81Dojo で小さく試す。** 規約上は最も安全。1日ほどで、取れる棋譜の量・質・段級位の絞りを確かめられる。結果次第で、案Aと組み合わせる。

## おすすめの順番(判断はユーザー)

1. 案A を土台にする(規約の問題がなく、すぐ始められる)。
2. 案E で81Dojoの棋譜が使えるか、半日〜1日で確かめる。
3. 将棋ウォーズの棋譜が欲しいなら、案D(HEROZに問い合わせ)を並行して出す。許可が出るまでは取らない。
