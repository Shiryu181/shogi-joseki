## 2. 書き方の決まりの案

### 2.1 型(1手の解説)

- **1文目 = 何のための手か。** 「◯◯して、△△します」の形で、動作と目的を1文に入れる。40字以内を目安。
- **2文目 = なぜそうするか。** 盤を見れば分かる理由を1つ。「〜なので」「〜と〜されるからです」。
- 理由が1文目で言い切れているときは、2文目は書かない(1文でよい)。
- **3文目以降 = 「くわしく」。** 次のものはすべてここへ回す。
  - 前置き(「相手が〜しても順は変わりません」)
  - 他の章との比較・章案内(「第3章と同じ」「本線と同じ」)
  - 手の差(「最善に近い」「同じくらい」「少し劣る」)。ただし「唯一の手」「ほかの手は大きく損をします」だけは2文目に残す(選択2)
  - 推測・確かめ方の注記(「(推測です)」「盤で確かめた」「一般的な説明」)
  - 他の戦法の名前、形勢
- 長さ: 1〜2文で60字以内(今の90%点は55字)。

### 2.2 理由の根拠と、書き分け

| 根拠 | 文末の書き方 | 「くわしく」に残すこと |
|---|---|---|
| 盤で確かめた(駒の位置・利き) | 言い切る | なし |
| 読み筋で確かめた(最善・同じくらい・唯一) | 言い切る | 読み筋の手順 |
| 出典の理由(盤・読み筋で未確認) | 「〜からです」と言い切るが、章の source に記録 | なし(source に出典) |
| 推測 | 「〜と考えられます」 | 「この理由は推測です」の1行 |

- 数字・エンジンの語は書かない(既存の決定)。読み筋の根拠は、章の evidence に残す。
- 盤の話は盤で確かめてから書く。今回の見本では、利き(例: 3三の角から2四、7三の銀から8四)を局面の駒の配置で確認した。

### 2.4 形勢を言う場所

- 案C: 今のまま、表記だけ統一。
- 表記: 互角(0〜40)/少し良い(40〜150)/良い(150〜400)/大きく良い(400以上)の4語に限る。「ほぼ互角」「やや」は使わない(選択6)。
- 境目付近の小さな上下(+35 と +45 のような)で言葉が入れ替わる場合は、段階が変わったとは言わず、前の言葉のままにする案(値は evidence に残す)。ただし、決めた物差しを動かすことになるので、使うなら要相談。

### 2.5 「要点なし」の手(動作だけ・理由がはっきりしない手)の書き方

読み筋で確かめると、理由を作れない手は大きく2種類あった。
- 同じくらいの手が複数ある駒組みの手(玉の寄せ方、端歩、金銀の上げ方)
- 他の手より少し劣るが、章の方針としてこの手で進める手

型は3つ(a は選択1のB を採ったとき):

- **(a) 理由がない・ほかでもよい型**
  - 例: 「端の歩を9四へ突きます。形を整える手で、決め手になる理由は見つかっていません。△2六歩・△4五歩でも同じくらいです。」
  - 1文目に動作と位置づけ、2文目に「ほかでもよい」ことを書く。「ほかの手」は読み筋で確かめたものだけ。
- **(b) 準備型(推測)**
  - 例: 「6筋の歩を6四へ突いて、6三の升を空けます。あとで7二の銀を6三へ上げるための準備と考えられます。」
  - 1文目は盤の事実、2文目は「考えられます」で推測と分かるようにする。
- **(c) ほぼ唯一型(理由は不明)**
  - 例: 「飛車を5二から5一へ引きます。この局面ではほかの手より形勢がはっきり良くなる、ほぼ唯一の手です。なぜ5一かは確かめていません。」
  - 読み筋で次善との差が大きいが、理由を言葉にできないとき。

## 4. 限界と、段階2でやること

- 80件の判定は1人(私)が読んで決めた。割合は ±10 ポイント。「要点」と「要点なし」の境目は揺れる(例: 玉を囲いへ向かわせます。は要点なしとした)。
- 読み筋は14局面だけ。500万ノード・Threads 1 の1回で、4000万ノードでの再測定はしていない。「同じくらい」は差が30前後以内という目安。
- 新しい文は見本であり、章のデータには反映していない。反映するときは、直した文ごとに aims.mjs のキー、章の evidence(消した読み筋の根拠)、形勢の言葉の表を一緒に直す必要がある。
- 用語の件数は語の有無を拾う機械の集計。読む人に分からないかどうかは私の想定(10〜5級、4〜1級)で決めた。
- 次の段階(選択後): 決まりを確定 → 見本の2章をデータに反映して画面で確認 → 残りの章を進める。
