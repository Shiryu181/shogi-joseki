## 2. 書き換えの決まり

- 画面に出る欄(note・comment・punishNote・aim・demos の text・line の note/comment・goalLabel など)に、評価値・損・差・深さ・ノード数・「d16」を書かない。
- 「エンジン」「新エンジン」「エンジンの読み筋」も書かない。出どころの説明(エンジンで選んだ、など)は検証メモ(evidence)に移す。
- 画面では手そのものの話として言葉で書く。推測は推測と書く。採点口調(悪くない、よくできた)にしない。`**` を使わない。
- 消した数字・測り方・出どころは、章の原稿の evidence(notes[i] の5つ目、devs と line の各手)に移す。build-joseki.mjs は JSON に出さない。
- 画面の文を直したら、aims.mjs のキー(note の文)も同じ文に直す(第7節)。

## 3. 選んでほしい点

**選択1: 出典の名前(Wikibooks 1.4、thirdfilerook「棒金とは」、将棋大図書館 など)を画面に残すか**

- A案(残す): 「出典(Wikibooks 1.4)の手です」のまま。根拠が見える。数が多くて文が長くなる。
- B案(検証メモへ移す): 「出典の手です」だけにする。名前は evidence に移す。文が短くなる。出典の信頼度は画面から見えない。
- 見本の表の「新しい文」は A案。B案にすると変わる行は第5・6節の末尾に並べた(ch1は6行、ch2は3行)。

**選択2: 出典にない手だと画面に書くか**

- 今は「エンジンで選んだ手です」と書いている。この言葉は消す。
- A案(「出典にない手です」と書く): 本線のどこから出典が無いかが画面で分かる。全部の手に付けると文が増える。
- B案(書かない): 文が短くなる。本線が出典のどこまでかは、章の冒頭の source に残す。
- 見本の「新しい文」は、元の文に「出典にない」と書いてあった2行(第5節の本線の手数18と、変化1の手数10)だけ A案、元が「エンジンの手です」だけだった行は B案にしてある。どちらかに統一したい。

**選択3: 形勢を言葉で書くとき、章の goalLabel(例: 形勢はやや先手持ち)と同じ表で書いてよいか**

- 第2節の対応表で仮に決めた。違う幅にしたい場合は教えてほしい。
